# COAGULATION!!

Coagulation is a GAME where you have to sling your blob around to avoid/DESTROY enemies. The corruption is FREEZING nature, so you must stop it while learning the backstory behind the corruption along the way.

When you're not moving, the enemies don't move. But when you do, they move too...
